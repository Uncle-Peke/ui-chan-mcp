ELI14 — セットアップ

S E T U Pういを動かすまで

クローンしてきてから、画面のすみっこにういが出てくるまで。 Claude Code と Claude Desktop、どっちでも動く。ただし入れるものが少し違う。

01まず、3つ用意する

ここが一番つまづくとこ。ういの絵はリポジトリに入ってない。 権利のある素材だから、別で持ってくる必要がある。

PSD は BOOTH の配布ページ から入手する（キャラクターガイドラインの範囲で利用）。 声を出すなら VoiSona Talk （テクノスピーチ・無料）を入れて、ボイスライブラリを1つ以上ダウンロードしておく。 Electron（ういの窓）は npm install で一緒に入る。VoiSona Talk が無くても 吹き出しは出るし口もパクパクする。声が出ないだけ。

02コマンドは4つ

01

持ってくる

リポジトリを好きな場所に置く。パスは後で使うから覚えとく。

git clone https://github.com/Uncle-Peke/ui-chan-mcp.git
cd ui-chan-mcp
02

材料をそろえる

これ1回でビルドまで終わる。npm run build は打たなくていい。

npm install
03

絵と、声のカギを置く

PSD を assets/ に置く。素材は ui-roid.booth.pm から。声を使うなら VoiSona Talk の「編集 > 環境設定 > API」で REST API を有効にして、そこで決めたパスワードを .env に書く。 

cp .env.example .env
# .env を開いて
#   UI_CHAN_TTS_USERNAME=you@example.com
#   UI_CHAN_TTS_PASSWORD=api-password
04

足りてるか見る

4項目まとめて確認してくれる。⚠️ は「無くても動く」って意味。

npm run doctor

.env は .gitignore 済み。シェルに export してもいいけど、 その場合は環境変数のほうが勝つ。

03入れ方は2つ。Desktop は両方いる

入れ方は「プラグイン」と「コネクタ」の2つ。プラグインは道具箱、コネクタは電源コードって 思っとくといい。Claude Code はプラグインだけで足りるけど、 Claude Desktop はプラグインを置いてくれるのに電源を挿してくれないから、両方いる。

Claude Desktop はプラグインの一覧に出しはするけど、中の MCP サーバを起動しない。 だから Desktop だけコネクタも登録する。Claude Code は逆に、プラグインが自分で起動するので コネクタを足すと同じものが二重に動く（壊れはしないけど無駄）。

04プラグインを入れる（Code / Desktop 共通）

Claude Code から3行。入れた内容は Claude Desktop にも共有されるので、 プラグインの登録はこの1回だけでいい。

01

置き場所を教える

Claude Code の中で打つ。パスは 02 で置いた場所。

/plugin marketplace add /path/to/ui-chan-mcp
02

入れる

/plugin install ui-chan@ui-chan
03

クローンとつなぐ（大事）

ターミナルで、クローンした場所で打つ。これを忘れると、あとでリポジトリを直しても Claude Code だけ昔のままになる。 

npm run link-plugin
04

開き直す

Claude Code は一度終了してもう一度開く。Claude Desktop も使うなら、そっちは 完全に終了してから起動（Mac は ⌘ + Q。ウィンドウを閉じるだけだと終わってない）。 設定 → プラグイン に「ういちゃんデスクトップマスコット」が出ていればOK。

/plugin install は、リポジトリを ~/.claude/plugins/cache/ にコピーして使う。つまりコピーが増えて、 直す場所が2つになる。npm run link-plugin はそのコピーを消して、クローンへの ショートカット（symlink）に置き換える。これで本物はクローンだけになる。 Desktop 側の追加ボタンは GitHub からの追加しかできないので、登録は Claude Code からやる。

05コネクタを入れる（Desktop に必要）

Claude Desktop で喋らせるにはこれが必要。1コマンドで終わる。 Claude Code しか使わないなら、ここは飛ばしていい。

01

登録する

クローンした場所で打つ。元の設定は .bak に残る。

npm run install-desktop
02

アプリを開き直す

⌘ + Q で完全に終了してから起動。+ メニューの コネクタ に ui-chan が出ていれば繋がってる（プラグインの棚とは別のところ）。

手で書きたいなら、設定（⌘ + カンマ）→ 開発者 → 設定を編集 で claude_desktop_config.json を開いて、"mcpServers" の中にこれを足す。 外すのは npm run install-desktop -- --remove。 

{
  "mcpServers": {
    "ui-chan": {
      "command": "<ui-chan-mcp を置いた場所>/bin/ui-chan-node",
      "args": ["<ui-chan-mcp を置いた場所>/dist/mcp-server.js"]
    }
  }
}
ここで "command": "node" と書くと動かない。アプリから起動された Claude Desktop は ターミナルとは別の環境で動いていて、そこからは node が見えないから。 bin/ui-chan-node は node を自分で探してくれる係。

06動いたかどうか

新しいセッションを開けば、勝手にういの窓が出てくる。出てこないなら、 先に単体で起動してみると原因が切り分けられる。

うんともすんとも言わないときは npm run doctor に戻る。 ❌ が出るのは「ビルドされてない」ときだけで、それ以外は動くはず。

07あとで直したとき

コードや台詞をいじったら、これだけ。プラグインもコネクタも同じクローンを見てるから、 片方だけ古い、みたいなことは起きない。

01

作り直す

次のセッションから反映される。Cue（表情）の .json だけなら保存した瞬間に反映されるので、これも要らない。

npm run build
02

もし /plugin install をやり直したら

コピーが復活してつながりが切れるので、もう一度これを打つ。

npm run link-plugin
