ELI14 — セットアップ

S E T U Pういを動かすまで

クローンしてきてから、画面のすみっこにういが出てくるまで。 Claude Code でも Claude Desktop でも動くよ。順番にやれば大丈夫。

01まず、3つ用意する

ここが一番つまづくとこ。ういの絵はリポジトリに入ってない。 権利のある素材だから、別で持ってくる必要がある。

PSD は BOOTH の配布ページ から入手する（キャラクターガイドラインの範囲で利用）。 声を出すなら VoiSona Talk （テクノスピーチ・無料）を入れて、ボイスライブラリを1つ以上ダウンロードしておく。 Electron（ういの窓）は npm install で一緒に入る。VoiSona Talk が無くても 吹き出しは出るし口もパクパクする。声が出ないだけ。

02コマンドは4つ

01

持ってくる

リポジトリを好きな場所に置く。パスは後で使うから覚えとく。

git clone https://github.com/Uncle-Peke/ui-chan-mcp.git
cd ui-chan-mcp
02

材料をそろえる

これ1回でビルドまで終わる。npm run build は打たなくていい。

npm install
03

絵と、声のカギを置く

PSD を assets/ に置く。素材は ui-roid.booth.pm から。声を使うなら VoiSona Talk の「編集 > 環境設定 > API」で REST API を有効にして、そこで決めたパスワードを .env に書く。 

cp .env.example .env
# .env を開いて
#   UI_CHAN_TTS_USERNAME=you@example.com
#   UI_CHAN_TTS_PASSWORD=api-password
04

足りてるか見る

4項目まとめて確認してくれる。⚠️ は「無くても動く」って意味。

npm run doctor

.env は .gitignore 済み。シェルに export してもいいけど、 その場合は環境変数のほうが勝つ。

03どっちの Claude で使う？

Claude Code（ターミナルのやつ）と Claude Desktop（アプリのやつ）、どっちでも動く。 両方に入れてもいいよ。ういは1人しかいないから、同じ子が両方から喋る。

右の2つが「なし」なのは、Claude Desktop にプラグインの仕組みが無いから。 喋る・表情が変わる・性格が入る、は同じように動くよ。

04Claude Code に入れる

Claude Code を開いて、この2行を打つだけ。パスは 01 で置いた場所。

01

置き場所を教える

/plugin marketplace add /path/to/ui-chan-mcp
02

入れる

/plugin install ui-chan@ui-chan
03

開き直す

Claude Code を一度終了して、もう一度開く。次に開いたときからういが出てくる。

05Claude Desktop に入れる

アプリの中に「追加」ボタンは無くて、設定ファイルに数行書くやりかた。 こわく見えるけど、やることはコピペだけ。

01

設定ファイルを開く

Claude Desktop の 設定（Mac は ⌘ + カンマ）→ 開発者 → 設定を編集。claude_desktop_config.json の場所が開くので、 そのファイルをテキストエディタで開く。

02

node の場所を調べる

ターミナルでこれを打って、出てきた1行をコピー。

which node
03

書き足す

ファイルが空っぽなら下をまるごと貼る。すでに何か書いてあるなら "mcpServers" の中に "ui-chan" の行だけ足す。 2か所を自分の環境に置き換えてね。 

{
  "mcpServers": {
    "ui-chan": {
      "command": "<which node で出た場所>",
      "args": ["<ui-chan-mcp を置いた場所>/dist/mcp-server.js"]
    }
  }
}
04

アプリを開き直す

完全に終了してから起動する（Mac は ⌘ + Q。ウィンドウを閉じるだけだと終わってない）。 入力欄のあたりに工具のアイコンが出ていれば繋がってる。

コマンドが平気な人は npm run install-desktop で 01〜03 が一発で終わる。 元の設定は .bak に残るし、npm run install-desktop -- --remove で戻せる。

うまくいかないときは、まず node の場所が合ってるか確認。 Claude Desktop はターミナルと違う環境で動くので、node とだけ書くと見つからないことがある。

06動いたかどうか

新しいセッションを開けば、勝手にういの窓が出てくる。出てこないなら、 先に単体で起動してみると原因が切り分けられる。

うんともすんとも言わないときは npm run doctor に戻る。 ❌ が出るのは「ビルドされてない」ときだけで、それ以外は動くはず。
