ELI14 — セットアップ

S E T U Pういを動かすまで

クローンしてきてから、画面のすみっこにういが出てくるまで。 コマンドは4つだけ。むずかしいのは1個もないよ。

01まず、3つ用意する

ここが一番つまづくとこ。ういの絵はリポジトリに入ってない。 権利のある素材だから、別で持ってくる必要がある。

PSD は BOOTH の配布ページ から入手する（キャラクターガイドラインの範囲で利用）。 声を出すなら VoiSona Talk （テクノスピーチ・無料）を入れて、ボイスライブラリを1つ以上ダウンロードしておく。 Electron（ういの窓）は npm install で一緒に入る。VoiSona Talk が無くても 吹き出しは出るし口もパクパクする。声が出ないだけ。

02コマンドは4つ

01

持ってくる

リポジトリを好きな場所に置く。パスは後で使うから覚えとく。

git clone https://github.com/Uncle-Peke/ui-chan-mcp.git
cd ui-chan-mcp
02

材料をそろえる

これ1回でビルドまで終わる。npm run build は打たなくていい。

npm install
03

絵と、声のカギを置く

PSD を assets/ に置く。素材は ui-roid.booth.pm から。声を使うなら VoiSona Talk の「編集 > 環境設定 > API」で REST API を有効にして、そこで決めたパスワードを .env に書く。 

cp .env.example .env
# .env を開いて
#   UI_CHAN_TTS_USERNAME=you@example.com
#   UI_CHAN_TTS_PASSWORD=api-password
04

足りてるか見る

4項目まとめて確認してくれる。⚠️ は「無くても動く」って意味。

npm run doctor

.env は .gitignore 済み。シェルに export してもいいけど、 その場合は環境変数のほうが勝つ。

03Claude Code につなぐ（2択）

プラグインで入れるのが楽。人格の読み込みも、ういの窓の起動も、全部ついてくる。

A

プラグインで入れる

Claude Code の中で打つ。パスは 01 で置いた場所。

/plugin marketplace add /path/to/ui-chan-mcp
/plugin install ui-chan@ui-chan
B

手で登録する

ターミナルで。声のカギは .env から読まれるので書かなくていい。

claude mcp add ui-chan \
  -- node /path/to/ui-chan-mcp/dist/mcp-server.js

04動いたかどうか

新しいセッションを開けば、勝手にういの窓が出てくる。出てこないなら、 先に単体で起動してみると原因が切り分けられる。

うんともすんとも言わないときは npm run doctor に戻る。 ❌ が出るのは「ビルドされてない」ときだけで、それ以外は動くはず。

立ち絵素材：雨衣（うい）／坂本アヒル様

利用は雨衣キャラクターガイドラインの範囲で。
