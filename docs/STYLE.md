# ドキュメントの書きかた

> **ドキュメントを書く・直すときに読む。** ここに書いてある型を守れば、どのページも同じ顔になる。
> 読む人は毎回レイアウトを学び直さずに済むし、書く人は迷わずに済む。

CSS は使えないので、**GitHub の Markdown でできることだけ**を組み合わせて統一感を作る。
凝ったことはしない。決めごとを少なくして、全部のページで必ず守るほうが効く。

---

## `01` ページの型

どのページも、この4つで始める。

```markdown
# タイトル（名詞。機能名か作業名）

> **いつ読むか。** 1〜2文で、このページが答える問いを書く。
> 別のページのほうが適切なら、そのリンクをここで出す。

---
```

<sub>リード文を引用（`>`）にしているのは、本文と視覚的に切り離すため。GitHub では
引用が左に縦線で表示されるので、それだけで「案内文」だと分かる。</sub>

## `02` 見出し

| レベル | 使いかた |
|---|---|
| `#` | ページに1つだけ。タイトル |
| `## \`01\` 見出し` | 大きな区切り。**番号を付ける**。区切りの前に `---` を入れる |
| `###` | その中の手順や項目。番号は付けない |
| `####` | 使わない。必要になったらページを分ける合図 |

番号は図解ページ（[SETUP.html](SETUP.html)）の `01` `02` と同じ役割で、
「いくつあって、いま何番目か」を読む人に渡すためのもの。

## `03` コールアウト（色）

GitHub Alerts は種類ごとに色が付く。**用途を固定して、色が意味を持つようにする。**

> [!NOTE]
> 青。前提・環境・仕様の補足。知らなくても進めるが、知っていると迷わないこと。

> [!TIP]
> 緑。近道・省略できること。「これ全部やらなくていいよ」の合図。

> [!IMPORTANT]
> 紫。守ってほしい約束。権利表記、命名規約、設計上の決めごと。

> [!WARNING]
> 黄。壊れる操作、ハマりどころ。やり直せるが痛いもの。

> [!CAUTION]
> 赤。取り返しがつかないもの。公開、削除、上書き。**滅多に使わない。**

<sub>1ページに何個も置かない。目安は2つまで。多いと色が意味を失う。</sub>

## `04` 表

説明が3つ以上並ぶときは、箇条書きより表にする。視線が止まる場所ができる。

- **1列目は「対象」**（id、ファイル名、コマンド、キー）。ここが揃うと読みやすい
- 記号・絵文字の列は `|:---:|` で中央寄せ
- 最後の列に「そうしないとどうなるか」を置くと、判断できる表になる

| 悪い例 | 良い例 |
|---|---|
| 説明を文章で3段落 | 表にして、1列目に対象、最後に結果 |
| `| 項目 | 説明 |` だけ | `| 項目 | 何が起きる | 省略すると |` |

## `05` 補足と強調

| 書きかた | 使いどころ |
|---|---|
| `<sub>小さい文字</sub>` | 注釈。読み飛ばしてよい情報。段落の末尾に置く |
| `**太字**` | その段落で1箇所だけ。多用すると効かなくなる |
| `` `コード` `` | ファイル名、コマンド、設定キー、Cue名 |
| `<kbd>Enter</kbd>` | 実際に押すキー |

## `06` ページの終わり

行き先を示して終わる。読み終えた人を放り出さない。

```markdown
---

<sub>次に読むなら [ページ名.md](.)（〜したいとき） / [ページ名.md](.)（〜したいとき）</sub>
```

## `07` 口調

| 場所 | 誰の言葉か |
|---|---|
| `README.md` | **ういちゃん本人**。「わたし」「きみ」。使う人向けの案内 |
| `docs/` | **書き手**。です・ます。事実と理由を淡々と |
| `persona/` `context/` | ドキュメントではない。**AI に注入される設定**。触ると振る舞いが変わる |
| `docs/ARCHITECTURE.md` | 実装者向け。設計判断と、そう決めた理由。**誰の環境でも同じことだけ**を書く（公開リポジトリなので、手元固有の事情は git 管理外の `CLAUDE.md` へ） |

> [!IMPORTANT]
> `docs/` でういちゃんの口調を真似しない。**楽しいのは README だけでいい。**
> 手順書が語尾で揺れると、読む側は情報の正確さを疑いはじめる。
