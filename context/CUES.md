# CUES — ういの Cue 早見表

うい（マスコット）の見た目＋声を操る唯一の単位が **Cue**。`cues/*.json`（1ファイル=1Cue、
`cue.schema.json` 準拠）にある名前を `set_cue(cue, text?, ...)` に渡すだけで、顔・腕・声色が
まとめて切り替わる。`set_expression`/`set_pose`/`set_face` のような部分操作ツールは存在しない。

**このファイルは実行時にロードされない、Cue選定・新規Cue制作のための参照ドキュメント。**
起動時に読み込まれるのは `cues/*.json` の中身と `cue.schema.json` だけ。

## 使い方の基本

- 場面に合う Cue 名を選んで `set_cue({ cue: "happy", text: "やったー！", reading: "やったー！" })`
- 無言で見た目だけ変えたいときは `text` を省略できる
- 声の抑揚を1行だけ変えたいときは `pitch`/`speed`/`volume`/`intonation` を渡す（Cueに焼き込まれた
  `voice.style_weights`/`alp`/`huskiness` の上にアドリブとして重なる）
- 存在しない Cue 名を指定すると `default` にフォールbackし、結果に `note` が付く
- 強さ違いは別の Cue 名（`angry`→`gekioko`、`happy`→`happy_strong` のように）。intensityパラメータは無い

## 新規Cue制作のためのパーツ・カタログ

`cues/*.json` の `select`/`show`/`hide` には生のPSDレイヤーパスをそのまま書く。以下は
そのパスを組み立てるための参照表（旧 `set_face`/`set_pose` が使っていたスロット分類を、
制作用メモとして残したもの。実行時のツールやconfigとしては存在しない）。

### 目は3階層になっている
- `!目/*<形>` … 目まるごとの形（ジト目・閉じ・上向き…）。`基本目セット` を選ぶと下2つで詰められる
- `!目/*基本目セット/!白目/*<白目>` … 白目のかたち（`基本目セット` のときだけ効く）
- `!目/*基本目セット/*<視線>` … 黒目の向き・種類（`基本目セット` のときだけ効く）

### `eyes` — 目まるごと（`!目/*...`、13）
| 名前 | どんな目 |
|---|---|
| `基本目セット` | 標準の目。これを選ぶと白目/視線で詰められる |
| `ジト目` | 半目のジト目。塩鮭・呆れ・「ふ〜ん」 |
| `○○` | まん丸見開き。びっくり |
| `ぐるぐる` | ぐるぐる目。混乱・目が回る |
| `＞＜` | ぎゅっと閉じた `><`。爆笑・痛い・きゃっきゃ |
| `ーー` | 一本線の閉じ目。眠い・真顔・悟り |
| `閉じ` | 穏やかに閉じた目。安らぎ・まばたき |
| `にっこり1` | 笑い目（控えめ） |
| `にっこり2` | 笑い目（大きめ・満面） |
| `細目` | 細めたドヤ目。にやり・自信家 |
| `細目ハート` | 細めた目＋ハート。ういおじ・でれ |
| `コンセント` | 光の消えた目（コンセント顔）。無・虚無・真顔ネタ |
| `上向き1` | 上目遣い（考え中） |
| `上向き2` | 上目遣い（強め・遠い目） |

### 白目（`!目/*基本目セット/!白目/*...`、3）
`白目基本` / `白目ジト`（半目・呆れの詰め） / `白目見開き`（かっと見開いた白目、衝撃）

### 視線（`!目/*基本目セット/*...`、10）
`正面1`(デフォルト) / `正面2` / `カメラ目線1` / `カメラ目線2` / `目そらし1` / `目そらし2`（強め、照れ・
気まずい） / `きらきら目`（ワクワク・尊い） / `ハート目`（love） / `ぐるぐる目` / `縮小`（恐怖・戦慄）

### 口（`!口/*...`、22）
`ん`=閉じ(標準) / `あ``え``お`=小さく開く / `お`=すぼめ丸口 / `あは`=笑い / `あはー`=大笑い /
`えへ`=てへ照れ笑い / `ほほえみ`=にっこり閉じ / `にし`=にやり(ドヤ) / `むふ`=含み笑い / `ほわ`=とろけ /
`ほあー`=ほへ〜(脱力) / `ゆ`=きゅっ(照れ) / `んー`=思案のハミング / `む`=むっ(ふくれ) / `え`(えー)=不満の口 /
`えあー`=あわあわ(困り) / `いー`=歯を食いしばる(力み・怒り) / `おおー`=感嘆の大口 / `おー`=おお /
`△`=三角口(緊張) / `うわー`=大口(絶叫・泣き) / `お`(小)=ぽかん

### 眉（`!眉/*...`、5）
`普通`(標準) / `上がり`=上げ眉(驚き・喜び) / `困り`=困り眉(下がり) / `怒り1`=怒り / `怒り2`=激おこ

### 頬・顔色（`!頬・顔色/*...`、7）
`頬1`(標準) / `頬2`(血色よい) / `頬赤め1`=照れ赤 / `頬赤め2`=真っ赤 / `青ざめ1`=青ざめ /
`青ざめ2`=真っ青 / `(非表示)`=頬色なし

### 重ねエフェクト（`show`/`hide` で指定）
`!汗・涙/汗1`=汗1滴(焦り) / `!汗・涙/汗2`=汗だく(パニック) / `!汗・涙/涙`=涙 / `!頬・顔色/かげり`=顔の影(暗い・絶望・げんなり)

### 腕（`!奥の腕/*...` / `!手前の腕/*...`）— 現在使用中のCueが焼き込んでいる組み合わせ
| 腕の見た目 | 使っているCue |
|---|---|
| 通常（`default`に焼き込み） | 全Cue共通の下地 |
| 傘さし | `normal_umbrella` |
| 両手ばんざい | `happy_banzai` |
| あご手（考え中） | `normal_think` |
| 腕組み | `smug_arms_crossed`, `normal_arms_crossed` |
| 腰に手 | `smug_hands_on_hips` |

以下は旧 `set_pose` カタログに存在したが、現在どのCueにも焼き込まれていない腕の組み合わせ。
新しいCueが必要になったときの生レイヤーパスの参照用（実在確認はPSD側で行うこと）：

| 名前（旧pose名） | 生レイヤーパス | 使いどころの目安 |
|---|---|---|
| `call` | `!奥の腕/*呼びかけ` + `!手前の腕/*呼びかけ` | 登場・「はいどうも〜」・挨拶 |
| `fist` | `!奥の腕/*基本` + `!手前の腕/*ぐっ` | やる気・気合い |
| `point` | `!奥の腕/*基本` + `!手前の腕/*指さし手前` | 強調・ういビーム代用 |
| `point_side` | `!奥の腕/*指さし横` + `!手前の腕/*基本` | 説明・案内・「あれ見て」 |
| `mic` | `!奥の腕/*マイク` + `!手前の腕/*基本` | 配信・実況・発表 |
| `palm_up` | `!奥の腕/*手のひら上` + `!手前の腕/*手のひら上` | どうぞ・提示・愛でる |
| `mouth_cover` | `!奥の腕/*口元` + `!手前の腕/*基本` | くすっ・「すいませんねぇ」・しまった |

> 注意: 傘（`normal_umbrella`）は吹き出しと干渉することがある。傘のときは長ゼリフを避けるか位置に注意。

## IdlingCue専用Cue（`idling_*`）

`cues/idling_yawn_1〜3` / `idling_lookaround_1〜3` / `idling_ponder` / `idling_doze_1〜3` /
`idling_giggle_1〜2` / `idling_sigh_1〜2` は、`ui-chan.config.json` の `idle.idlingCues`
（あくび・きょろきょろ・ぼんやり・うたた寝・くすくす・ため息）が内部的に参照する、無言の一瞬の
表情変化用Cue。他のCueと形式は同じだが、単体で場面に当てる想定ではなく複数ステップの一部として
使うために作られている。`set_cue`から直接呼んでも動作はするが、通常は呼ばない。
